# 单集简介：单集级活字段 + 合成快照

**Status**: accepted

**单集简介 (Episode Notes)** = 单集级（这一集）的简介描述文本（讲什么、看点），与节目级的**节目简介**（整档节目讲什么，属节目元数据）分层：

- **源头**：`episodes.show_notes`（text、可空）——编辑页文本侧编辑的活字段；用户手写，或让写稿大师在会话里代笔、确认后落进字段。
- **时机**：合成时把该字段**快照**进产物文件包的 `notes.md`（ADR-0008）；重新合成 = 整包替换，但源头在单集上，快照随之重建、不丢。
- **形态**：一段话简介（讲什么、看点）；可空（空则产物包不落 `notes.md`）；MVP **不自动生成**。

**Why**:

- **合成 = 确定性流水线（ADR-0005）**：单集简介若是"合成时 AI 自动生成"就违反这条。AI 参与只发生在文本侧（写稿大师代笔），合成只做确定性快照。
- **重合成 = 整包替换（ADR-0008）**：用户写的内容如果只存在产物里会被冲掉；活字段作源头 → 快照可重建。
- **分层**：节目简介（节目级，属节目元数据，跨单集不变）与单集简介（单集级，一集一份、随产物走）是两个不同层级，不冲突——对应真实播客（如小宇宙）的「节目简介 / 单集简介（show notes）」。

**Consequences**:

- `episodes` 增 `show_notes text default ''`；产物包 `notes.md` 由它快照而来（空则省略）。
- 写稿大师工具面不变（read / add / edit / retrieve）；代笔走会话文本，不进工具面。
- 单集简介不进写稿大师的 AI 上下文（它是成品描述，不是脚本内容）。
