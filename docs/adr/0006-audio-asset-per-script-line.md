# 音频素材跟随脚本行；素材库是共享容器（BGM/音效），不含对白

**Status**: accepted

**音频素材 (Audio Asset)** 是领域一等公民：脚本行合成出的单行音频（clip），**跟随脚本行**（script_line_id UNIQUE，每行 0..1 份），重合成时替换旧素材。它是后期编辑的原子单位（携带文本 / 说话人 / 时长）。

**素材库 (Asset Library)** 是**工作间级共享容器**，只装可复用资产（BGM / 音效 / 垫乐），跨集复用、不绑定单集。**对白素材不进素材库**——对白跟随脚本行（生命周期不同：对白随行合成替换、随行删除清理；库资产长期存在、跨集共享）。

**Why**:

- **对白 vs 库资产的生命周期不同**是分两个容器的根本原因：对白绑定脚本行（改台词/改指令重合成替换、删行清理），BGM 是长期共享资产（这集用了下集还能用）。放进同一个库要么污染其他集、要么无法跟随行清理。
- 素材（clip）是真实音频软件的最小公共单位（Audacity/Reaper/Premiere/DaVinci 的 clip/region/item），对齐后期时间线心智。
- 缓存键 = script_line_id，不做内容 hash（原决策保留）：主战场是单集内试听 → 调整 → 拼接循环，简单、失效路径可枚举。

**Consequences**:

- **音频素材**（跟随脚本行）：
  - 改台词 / 改指令 → 该行素材作废，重合成（单行、精准）
  - 强制重新生成 → 显式重写（绕过素材 / 清后重生成）
  - 换音色 / 换 TTS 模型 → 批量重写所有受影响行的素材
  - 改停顿 / 改语速 → 只重拼接，不重写（后期参数，ADR-0004）
  - 试听 = 单行合成入口，与批量共用同一条流水线与同一份素材
  - 素材随脚本行级联清理（script → script_lines → audio_assets ON DELETE CASCADE）
- **素材库**（共享，工作间级）：装 BGM / 音效 / 垫乐，跨集复用；后期从库取垫乐 + 从单集取对白 → 拼成 master。MVP 只预留模型（数据表/字段），不实现混音功能。
- **产物（master）不缓存**：它是便宜的，按脚本存 artifacts（0..1、重新合成替换）。
- 文本改动触发该行素材重合成（ADR-0001 单层模型、ADR-0003 确认门之后）。
