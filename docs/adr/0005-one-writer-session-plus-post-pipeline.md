# 一个写稿会话 + 非 AI 后期流水线

**Status**: accepted

文本层只有一个 AI 会话：**写稿大师**（工具 read / add / edit / retrieve），负责整个文本（台词 + 指令）。音频侧是**非 AI 的确定性后期流水线**（合成 + 拼接 + 停顿/语速 + 响度 + 时间戳），不是会话、没有 AI。

**Why**: 指令式引擎（qwen3-tts-instruct-flash）下，"调音" = 改指令 = 改文本，写稿大师的 edit 工具天然覆盖；停顿/语速又落到后期流水线（非 AI）。于是音频侧没有第二个 AI 会话的立足点——把音频制作拆成"脚本制作（文本，AI）" + "后期（音频，流水线）"是最自洽的切法。

**Consequences**:

- 只有一个 AI 会话（写稿大师），一集一个会话线程，跟着单集挂（conversation ↔ episode）。
- 后期不是 AI 会话，但**是同一编辑页的下半区**（音频工作区）：脚本行列表 + 停顿/语速参数 + 默认间隔规则；用户在同一窗口试听单行、触发合成、播放 master。时间线 UI 是增强，仍是同一素材序列模型的另一种视图。
- Auditor 仍是唯一子代理，隔离上下文、只用校验工具，与写稿大师平级，不归属任何一方。
- 上下文只追加 ChangeSet（ADR-0002）语义保留：用户改台词/改指令也追加，Agent 工具发起的修改不追加。
