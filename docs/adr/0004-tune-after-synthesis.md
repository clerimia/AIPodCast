# 逐行微调发生在合成后的试听环节，微调的是脚本行的 TTS 配置，不随内容冻结

**Status**: accepted

逐行微调（停顿 / 语气 / 语速 / 情感）不是写稿动作，而是"听后调"——由**调音大师**（脚本页的独立 AI 会话）在合成完成后逐行配置脚本行的 TTS 配置。脚本内容（文本 / 说话人）一个字节都不动，TTS 配置只作为合成输入，不冻结在脚本内容里。

**Why**: 微调的本质是听完再改，属于"表现"而不是"内容"。按页面拆职责后，写稿大师（编辑页）管稿件内容，调音大师（脚本页）管脚本行的 TTS 配置，工具面完全不同（写稿大师没有 tune，调音大师没有 add/edit），所以调音大师不能作为主会话的子代理——它是与写稿大师平级的独立会话（ADR-0005）。内容与表现分离：内容（稿件行 / 脚本内容）不可变，表现（每行 TTS 配置）作为合成输入随版本实时生效——与"音色不随稿件冻结"（ADR-0001）是同一套边界。

**Consequences**: 一版脚本 = 稿件行 + 每行 TTS 配置（定稿时默认值，调音大师改）。重新合成时，被调过 TTS 配置的行缓存键变化（hash 含 pause/tone/speed/emotion）→ 按"新合成"算；未调且内容未变的行照常命中缓存。微调不是新定稿：改 TTS 配置不新增"第 N 版"，只覆盖该版脚本的合成输出。
