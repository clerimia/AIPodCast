# 微调 = 改指令（文本）+ 改后期参数（停顿/语速），不重写素材

**Status**: accepted

对单行听感的调整是两种操作，分开建模：

1. **改指令**：直接编辑脚本行的"怎么说"（语气 / 情感 / 风格，`input.instructions`）——这是文本编辑，在写稿会话里做。改指令 → 该行音频素材作废，重合成（ADR-0006）。
2. **改后期参数**：停顿 / 语速——**拼接层参数**。停顿 = 相邻素材间的间隔（gap，可为负=重叠），语速 = 素材变速（atempo）。改它们 → **只重拼接，不重写素材**。

**Why**: 指令式引擎（qwen3-tts-instruct-flash）里听感 = 指令文本（引擎原生）+ 停顿/语速（ffmpeg 后期），两者性质不同：

- 指令改变合成内容 → 必须重合成，花钱、重写素材；
- 停顿/语速是后期几何变换 → 只重拼接，不花钱、不重写素材。

这个分离对应真实音频软件的素材模型：素材（clip）在时间轴上排列，停顿 = 相邻素材的间隔（拖开=变长，重叠=交叉淡化），变速 = 素材级 time-stretch。没有"素材自带 padding"的模型（调研见 `docs/research/`）。

**Consequences**:

- 脚本行 = 说话人 + 台词 + 指令；停顿/语速不在脚本行文本里，是后期（拼接）参数。
- 微调不新增版本：改指令 / 改后期参数都只影响合成输出，一集就是当前文本 + 产物（ADR-0001 无版本）。
- 改指令 → 该行素材重合成；改停顿 / 改语速 → 只重拼接。未改的行照常命中素材。
- 后期参数 MVP 用默认规则（停顿档位 / 语速档位），时间线手动调 gap 是增强。
