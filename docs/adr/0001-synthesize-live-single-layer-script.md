# 合成读活脚本（单层文本），无稿件快照、无版本

**Status**: accepted

脚本是**单层文本**：脚本行 = 说话人 + 台词 + 指令，活实体、随时可改。合成（含重新合成）直接读这份活脚本，**没有"稿件 → 定稿 → 脚本快照"的两层，没有内容冻结，没有多版脚本**。

**Why**: 指令（语气/情感）是文本（qwen3-tts-instruct-flash 的 `input.instructions`），"调音"本质就是改文本。写稿与调音因此合并为一个文本层，不需要独立的调音层、内容冻结或多版快照：

1. **听感全由指令文本控制**：音色之外的表达（语气/情感/风格）直接在活脚本上改，没有独立调音对象需要"内容别乱动"。
2. **无版本历史**（MVP 不做多版）：一集 = 当前文本 + 产物，改了就改。

**代价（有意的取舍）**: 行是音频的源头——改台词、改指令都会触发该行音频素材重合成（ADR-0006）。这是单层模型成立的前提，用户已确认接受。

**Consequences**:

- 一集一份脚本（一组脚本行），无版本号、无定稿动作。
- 合成读活脚本：逐行取音频素材（命中复用 / 未命中合成）→ 后期拼接 → 写产物。
- 音色不随内容冻结：脚本行只记 speaker_id，重新合成跟随当前说话人配置。
- 任何文本改动（台词 / 指令）都会让该行素材作废，下次合成重生成（见 ADR-0006）。
