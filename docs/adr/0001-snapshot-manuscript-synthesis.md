# 合成只针对"脚本"（定稿生成的不可变快照），而不是活稿件

**Status**: accepted

合成（含重新合成）只读"脚本"——每次定稿时把当前稿件的内容冻结成的一版不可变快照（脚本行 = 稿件行 + 默认 TTS 配置），而绝不读正在编辑的稿件。

**Why**: 编辑与合成因此完全解耦。合成是脚本行上的后台状态机（待合成 → 合成中 → 已合成），永远不会和用户正在编辑的稿件争同一份数据——无需锁、无需冻结稿件，定稿只是生成脚本的动作。换音色后对某版脚本"重新合成"即用新音色重做（音色不随内容冻结）。

**Consequences**: 脚本内容随定稿冻结，但行只引用说话人 id，音色在定稿后仍可变，重新合成会跟随当前说话人配置。脚本表按定稿顺序形成版本历史；一版定稿 = 一版脚本。
